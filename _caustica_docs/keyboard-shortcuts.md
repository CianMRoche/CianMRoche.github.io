Press `?` (or **Shortcuts** in the top bar) for this list in the app.

| Key | Action |
|---|---|
| `1` / `2` / `3` | Lens / source / hybrid placement tool on or off (then click a plane viewer, or on a computer the image, to place) |
| `4` | Mask tool on or off, while there is an observation (<a href="/caustica-documentation/background-image/#delensed-view">§7</a>) |
| `C` | Critical curves and caustics on or off |
| `I` | Lensed image |
| `K` / `G` / `M` / `A` | Convergence κ / shear γ / magnification \|μ\| / deflection \|α\| map (<a href="/caustica-documentation/lensing-quantities/">§4</a>) |
| `T` | Fermat potential (<a href="/caustica-documentation/lensing-quantities/#fermat-potential">§4</a>) |
| `P` | Parity (<a href="/caustica-documentation/lensing-quantities/#parity-map">§4</a>) |
| `N` | Image number (<a href="/caustica-documentation/lensing-quantities/#image-number">§4</a>) |
| `B` | Source magnification (<a href="/caustica-documentation/lensing-quantities/#source-magnification">§4</a>) |
| `S` | Unlensed (<a href="/caustica-documentation/lensing-quantities/#unlensed">§4</a>) |
| `U` | Delensed image (<a href="/caustica-documentation/background-image/#delensed-view">§7</a>) |
| `H` | Hide or show the selected object |
| `O` | Remove all objects from the selected plane |
| `X` | Delete the selected plane |
| `[` / `]` | Select the previous / next plane, in order of redshift |
| `,` / `.` | Previous / next panel on the right (computer) |
| `R` | Start or stop recording |
| `L` | Ruler on or off |
| `D` | Dark or light theme |
| `F` | Full screen: only the image (`F` or `Esc` to leave) |
| `?` | This list |
| `Cmd/Ctrl` + click | Add an object to the selection or remove it (drag a box on the image to select several) |
| `Cmd/Ctrl` + `C` / `V` | Copy the selected object / paste a copy. With a pasted-image source selected, `V` pastes a picture from the clipboard into it |
| `Cmd/Ctrl` + `Z` | Undo |
| `Cmd/Ctrl` + `Shift` + `Z`, or `Cmd/Ctrl` + `Y` | Redo |
| `↑ ↓ ← →` | Move the selected object (hold to speed up) |
| `Delete` / `Backspace` | Delete the selected object or ruler measurement |
| `Esc` | Deselect the ruler measurement, else turn the ruler off, else turn the placement tool off, else deselect the object |
